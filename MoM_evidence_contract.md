# MoM Evidence Contract

This file is the canonical evidence table for the Mechanics of Meaning (MoM) paper.

**Rule:** every empirical claim in `paper/MoM_paper.md` must be traceable to one or more Evidence IDs from this table, either inline in the manuscript or through the Appendix A.2 claim-to-artifact map.

Evidence ID namespaces:
- `E#`: empirical result claims backed by checked-in run artifacts (CSV/JSON).
- `R#`: run provenance / integrity facts backed by manifests and run metadata.
- `C#`: implementation guarantees backed by code in this repo (pipeline behavior, not run outcomes).

Conventions:
- **CI** is one of: `✓` (present for primary metric), `varies` (present for some listed metrics), `–` (not applicable / not reported).
- **Controls** lists run-time control conditions reported in the artifact.
- **Bootstrap unit** is the resampling unit used for reported CIs (when applicable).
- **Artifact(s)** are repo-relative paths in this workspace.
